# AutoJP

Repositorio de automatizaciones para el flujo diario del equipo. Cada automatización está en su propia carpeta con su propio README.

## Automatizaciones

| Carpeta | Qué hace |
|---|---|
| [`asignar-casos-empleados`](asignar-casos-empleados/README.md) | Asigna casos a cada empleado en una UI web según un XLSX, fila por fila. |
| [`mails-sin-responder`](mails-sin-responder/README.md) | Arma un reporte diario con los mails de las casillas compartidas de Outlook que nadie del equipo respondió. |
| [`reasignar-casos-pega-lob`](reasignar-casos-pega-lob/README.md) | Reasigna casos de Pega a la basket de cada LOB, fila por fila, desde un XLSX. Borrador: arranca en modo simulación. |

## Agregar una nueva

1. Creá una carpeta nueva con un nombre descriptivo, en minúsculas y con guiones.
2. Adentro, poné el script y un `README.md` con instalación, configuración y uso.
3. Sumala a la tabla de arriba.
